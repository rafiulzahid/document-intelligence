# Sample files

Small files for trying the system right after setup. Upload them on the home page (drag and drop several at once)
or with `curl` (see the main README). Expected results (checked with the API; upload them in this order so the duplicates point to earlier files):

| File | What it shows | Expected result |
|---|---|---|
| `northwind_10260.pdf` | Digital PDF with a text layer | Processed; fields and line items extracted. Supplier is flagged as missing because the document has no seller name (the system does not invent one) |
| `dup_exact_10260.pdf` | Same invoice uploaded again | `DUPLICATE` issue pointing to the earlier upload (upload it after `northwind_10260.pdf`) |
| `planted_10265.pdf` | Invoice with a wrong line amount (30 × 31.20 shown as 946.00) | `LINE_ITEM_MATH` and `LINE_SUM_MISMATCH` errors, status *needs review* |
| `degraded_10260.jpg` | Low-quality scan of the same invoice (simulated) | OCR + extraction, and a `DUPLICATE` of `northwind_10260.pdf` found by invoice number although the file is different |
| `katana_test_000.png` | Scanned invoice image | OCR + extraction, status *valid* |
| `multipage.tiff` | Two-page TIFF, one invoice per page | Two invoices; the first page is the invoice in `katana_test_000.png`, so it is flagged `DUPLICATE` |
| `csv_10250.csv` | Invoice as CSV | Read without OCR or LLM (table mapping) |
| `xlsx_multisheet.xlsx` | Workbook with several invoices on separate sheets | One invoice per sheet |
| `northwind_ledger.xlsx` | Accounting ledger (19 invoices in one sheet) | Use it on the **Cross-verify** page against `northwind_10260.pdf`: invoice 10260 is matched field by field |
| `truncated.pdf` | Broken PDF | Rejected with `CORRUPT_FILE`, the API keeps running |
| `password_protected.pdf` | Encrypted PDF | Rejected with `ENCRYPTED_PDF` |

Without an LLM (`DOCINTEL_LLM_PROVIDER=none`) the rules baseline is used. Digital PDFs and spreadsheets still work
well; OCR'd scans such as `degraded_10260.jpg` lose some line items.

Sources and licenses: Northwind invoices (Apache-2.0) and Katana ML invoices (MIT), converted or modified by
`Code/prepare_dataset.py`. The corrupted files were generated by the same script.
